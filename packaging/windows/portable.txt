SimplyPDF portable mode

While this file sits next to simplypdf.exe, SimplyPDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the SimplyPDFData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move SimplyPDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\SimplyPDF and
%LOCALAPPDATA%\SimplyPDF) instead. If SimplyPDFData can't be written (for example on a read-only
drive), SimplyPDF says so and uses the per-user folders instead.
