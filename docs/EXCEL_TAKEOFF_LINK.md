# Excel quantity-linked estimate (ENG-08.09)

SimplyPDF exports a versioned `Takeoff` worksheet with a workbook-defined range named `TakeoffData`. Excel's built-in **Power Query** can import that range into a separate estimate workbook. This is a refreshable link, not a live cell-by-cell connection or a background watcher.

## Connect an estimate

1. Export a **complete** takeoff XLSX snapshot from SimplyPDF to a stable, absolute file path, for example `C:\\Estimates\\Takeoff.xlsx`. The current snapshot export refuses to overwrite an existing workbook; managed refresh and overwrite are separate, unfinished milestones ENG-08.05/08.06.
2. In a **separate** Excel estimate workbook, select **Data → Get Data → From File → From Excel Workbook**, select the takeoff workbook, and choose the **TakeoffData** defined name. Choose **Transform Data**, verify that the first row is promoted to headers and `Value` is numeric, then **Close & Load To…** a table named `TakeoffData`.
3. Alternatively, in Excel's **Blank Query → Advanced Editor**, paste the M script generated by Rust `simplypdf_measure::xlsx::excel_power_query_source(Path::new(absolute_path))`. This helper validates the path, escapes quotation marks, selects the defined name, and assigns the 14 schema-v1 column types. The helper is a library API; there is not yet a desktop button or CLI command to copy the script.
4. Reference the loaded Excel table in your estimate using structured formulas such as `=SUMIFS(TakeoffData[Value],TakeoffData[Unit],"ft",TakeoffData[Material],"Copper")`. **Always filter by Unit**: adding feet, square feet, and counts together is incorrect. Key reconciliation of individual rows by `Annotation ID`, not by sheet position.
5. After a new takeoff workbook is safely published at the same path, choose **Data → Refresh All** in Excel. Check for refresh errors, the schema version, and expected measurement counts before trusting totals. Excel may cache stale data if the source file is locked or unavailable. The estimate workbook should not overwrite the source workbook.

## Compatibility and limitations

- Excel for Windows desktop with Power Query is the primary supported target; available menus and automatic refresh options vary by Excel version/platform.
- Power Query is a **pull** refresh. SimplyPDF does not currently trigger Excel refresh automatically.
- The current exporter is an immutable snapshot writer: you cannot simply re-export over the same path. A managed publisher is required for repeatable same-path refresh. Until that is implemented, publish a new file and change the Excel query's source path, or use a separately managed stable copy with appropriate safeguards.
- The named range contains the header and all 14 schema-v1 columns. Empty takeoffs have a header-only range. The source path and access permissions must remain valid.
- Integration and Excel UI smoke tests, managed same-path publishing, and exposing the generator in the desktop/CLI remain acceptance blockers before checking ENG-08.09.
